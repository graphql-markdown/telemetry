Reading this dashboard

n<5 suppressed: any value with fewer than 5 events over the selected range is hidden and counted as suppressed.

Accepted biases

Opt-out, blocked-network and corporate-proxy users are undercounted. Custom formatters and loaders are masked as "custom". firstRun is approximate (especially in containers). Fake events are only mitigated by the anti-abuse layers.

Interpreting totals

Events are an upper bound, distinct configs a lower bound; the true number lies in between. Local and CI units differ (one event per distinct config per machine vs one per CI run); "all" adds them together. Totals of debounced measures are sums of daily values.
